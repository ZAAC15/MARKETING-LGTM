# apps/web

Frontend Next.js App Router con TypeScript, Tailwind CSS, ESLint y Lucide React.

```powershell
npm install
npm run dev
```

Verificaciones locales: `npm run build`, `npm run lint`, `npm run typecheck`.

El logo corporativo original está en `public/branding/logo-lgtm.png`. Reemplaza ese archivo únicamente cuando el equipo proporcione una nueva fuente autorizada.
